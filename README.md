Proyek web scraping menggunakan Python untuk mengambil data perusahaan dari sebuah website dan menyimpannya dalam format CSV yang siap dianalisis.

## 📌 Ringkasan Proyek

Notebook ini memuat langkah pengambilan data dari halaman web, pembersihan hasil, dan penyimpanan ke file `companies.csv`.

## 🎯 Tujuan

- Mengotomatiskan pengambilan data dari website.
- Mengubah data HTML tidak terstruktur menjadi tabel yang rapi.
- Menyimpan hasil dalam CSV untuk analisis lanjutan.

## 🛠️ Tools

- **Python**
- **Jupyter Notebook**
- **CSV** sebagai format output

## 📁 Struktur Repository

```
Scraping-data-from-website/
├── Scraping data from website.ipynb   # Kode scraping
├── companies.csv                      # Hasil scraping
└── README.md
```

## 🚀 Cara Menjalankan

1. Clone repository:
   ```bash
   git clone https://github.com/achmadhavid/Scraping-data-from-website.git
   cd Scraping-data-from-website
   ```
2. Install dependensi yang digunakan di notebook (misalnya `pip install pandas requests beautifulsoup4 jupyter`).
3. Jalankan notebook:
   ```bash
   jupyter notebook "Scraping data from website.ipynb"
   ```
4. Hasil akan tersimpan sebagai `companies.csv`.

## ⚠️ Catatan

Gunakan scraping secara bertanggung jawab: patuhi `robots.txt` dan ketentuan layanan website sumber, serta hindari mengirim permintaan berlebihan.
